# arthurthiele.com

Personal site: writing and small tools. Astro, static, deployed to GitHub Pages on push to `main`.

```
yarn install
yarn dev        # local preview at http://localhost:4321
yarn typecheck  # tsc
yarn test       # vitest
yarn build      # output to dist/
yarn ship       # deploy: checks, fast-forward main, push, wait for Pages, smoke-test every page live
```

`yarn ship` runs from `main` or from a feature branch (which it fast-forwards into `main`). Uncommitted changes
never deploy; it lists them so nothing is left behind by accident.

## Layout

- `src/content/writing/`: posts as markdown. Frontmatter is validated at build time, so a malformed post fails the
  build rather than publishing broken.
- `src/tools/<tool>/`: each tool's code and data. Add new tools to `src/siteTools.ts` so they appear on the home and
  tools pages.
- `src/styles/global.css` holds structure; `src/styles/theme.css` holds the look (the "grimoire" design). Its art in
  `public/themes/` is generated by `scripts/themeArt.py` (seeded, so reruns reproduce it).

## Percentile converter data

Each dataset has a build script in `scripts/percentileData/` (run with `uv run scripts/percentileData/<name>.py`)
that downloads its source into `scripts/percentileData/.cache/` and writes JSON to
`src/tools/percentileConverter/data/`. Sources, licences and caveats are shown on the tool page under "About the data".

- The NCD-RisC server drops connections mid-download; `bodyMeasurements.py` resumes and validates the file.
- The CDC CDN blocks scripted downloads, so the NHANES percentiles in `bodyMeasurements.py` are transcribed by hand.
- `wealth.py` downloads WID's full bulk dataset (~880 MB, cached) and caches a compact extract, so reruns take seconds.
